# SpendWise Dashboard

SpendWise is a personal budgeting dashboard that helps users track expenses across categories.

## What it does
Visual dashboard + JavaScript logic to calculate remaining balance.

## JavaScript Concepts Implemented
- Variables: let, const for budget/expense data
- Data Types: Number, String
- User Input: prompt() to collect budget and expenses
- Calculations: subtraction for balance, percentage
- Functions: calculateBalance(), calculatePercentageSpent(), getSpendingStatus()
- Output: console.log()

## How variables are used
budget, expenses store amounts. userName stores user. remainingBalance stores result.

## How user input is collected
Using prompt() which asks for budget and expenses and Number() converts to numbers.

## How calculations are performed
calculateBalance does budget - expenses.

## How functions help organize code
Each function handles one job: balance calc, percentage, status check.
